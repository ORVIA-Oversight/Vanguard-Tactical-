# Vanguard Tactical — Production Reset Baseline

**Reset date:** 28 September 2026  
**Canonical branch:** main  
**Purpose:** Establish one controlled production baseline after multiple design, positioning and deployment passes.

## Current canonical direction

Vanguard Tactical is a commercial, human-led operational platform. It is broader than the sponsored airsoft programme.

Primary proposition:
- Operational command
- Field awareness / ATAC
- Communications / PTT
- Readiness
- Actions and decision record
- Human authority remains explicit

Secondary commercial structure:
- Individual
- Team
- Organiser / Site
- Enterprise
- White Label
- Global localisation

Airsoft:
- Airsoft is a Sport & Recreation use case, not the parent brand identity.
- 6 Troop is the sponsored proving team.
- 7 Troop is the reserve / augmentation element.
- Vanguard Tactical remains commercially separate from both teams.

## Brand baseline

Primary identity:
- Deep navy
- Champagne gold
- Clean premium editorial layouts
- Witness Room design DNA as the ORVIA web reference
- New Vanguard compass / helmet / journey mark
- New favicon mark

Approved design principles:
- wide-screen editorial layouts
- light / dark / light section rhythm
- restrained tactical imagery
- product UI shown as product
- mobile responsive
- no gamer / aggressive aesthetic
- commercial, scalable identity

## Deployment truth

The GitHub/Vercel application build and the public domain must be treated separately.

A successful Vercel deployment does not prove that vanguardtactical.co.uk is routed to that deployment.

The public domain must display the current Vanguard application before production deployment is considered complete.

## Reset rule

From this point:
1. main is the canonical source.
2. Do not reintroduce older storefront / tactical equipment / legacy shop content.
3. Do not revert Vanguard to an airsoft-only brand.
4. Preserve backend/auth/Supabase functionality unless a verified change requires modification.
5. New design changes must align with the current Vanguard brand and Witness Room-derived web system.
